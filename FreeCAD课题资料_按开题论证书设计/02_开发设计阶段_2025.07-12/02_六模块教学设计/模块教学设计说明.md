# 六模块教学设计说明

> 本说明解释六模块教学设计PDF与开题论证书的对应关系。

## 模块对应关系

| 论证书模块 | 教学设计PDF文件 | 说明 |
|---|---|---|
| 模块一：3D打印新视界与STEAM启蒙 | 模块一_3D打印新视界与STEAM启蒙.pdf | 对应论证书模块一 |
| 模块二：手动建模基础（FreeCAD） | 模块二_手动建模基础与实践（FreeCAD）.pdf | 论证书明确"以FreeCAD为例" |
| 模块三：编程建模入门 | 模块三_编程建模入门与逻辑构建.pdf | 对应论证书模块三 |
| 模块四：编程建模进阶 | 模块四_编程建模进阶与项目挑战.pdf | 对应论证书模块四 |
| 模块五：3D打印准备与切片 | 模块五_3D打印准备切片操作与实践.pdf | 对应论证书模块五 |
| 模块六：综合STEAM项目 | 模块六_综合STEAM项目设计与成果展示.pdf + 模块六附件_毕业项目.pdf | 论证书模块六含综合项目与成果展示 |

## 软件说明

全部模块统一使用FreeCAD（论证书模块二明确"以FreeCAD为例"）。不用3DOne。

## 注意

原教学设计PDF中有"模块六：毕业项目"，在论证书框架下归入模块六"综合STEAM项目设计与成果展示"的一部分，作为附件保留。
