## 一、文件目的

本说明用于明确数据平台当前所含数据的性质、来源与使用边界,避免在课题中期检查与后续研究中出现数据口径混淆。依据中期检查材料送审前核对事项第 3、4 条要求:
- 校本课程总体测评与 FreeCAD 专项测评分开表述,不混用数据。
- 数据平台演示数据继续保留"演示数据"标识,不写入研究结论。

## 二、数据平台功能定位

数据平台是课题组为**开展 FreeCAD 课程专项研究**而开发的工具,功能包括:

| 模块 | 功能 | 说明 |
|---|---|---|
| 概览 | 显示均值、六维能力雷达图 | 实时计算,基于当前导入数据 |
| 数据录入 | 单条录入匿名编号、前后测、六维、作品评分 | 支持 Web 端直接录入 |
| 学生档案 | 按匿名编号查询个人记录 | 不存储姓名,姓名与编号对应表由学校单独保管 |
| 分析报告 | 生成汇总文字报告 | 基于当前数据自动生成 |
| 数据导出 | 导出 CSV 与 JSON 备份 | 用于归档与跨设备迁移 |

**字段定义**:

| 字段 | 含义 | 取值范围 |
|---|---|---|
| id | 匿名编号 | 字符串,如 S01 |
| pre | 前测总分 | 0—100 |
| post | 后测总分 | 0—100 |
| space | 空间想象维度 | 0—100 |
| decompose | 问题分解维度 | 0—100 |
| parametric | 参数化思维维度 | 0—100 |
| debug | 调试与迭代维度 | 0—100 |
| engineering | 工程实践维度 | 0—100 |
| interest | 学习兴趣维度 | 0—100 |
| project | 作品评分 | 0—100 |

平台数据保存在浏览器本地存储(localStorage),不依赖服务器,更换电脑、浏览器或清除浏览器数据后不会自动带回。每次正式录入或导入后,必须导出 CSV 与 JSON 备份。

## 三、当前数据性质声明

### 1. 当前 60 人数据为系统测试用演示数据

数据平台当前截图与所附 `演示测评数据_60人.csv` 中的 60 条记录,**性质为系统测试用演示数据**,仅用于验证:
- 页面渲染、图表绘制、六维雷达图功能可用;
- 数据录入、保存、查询、导出、导入流程可用;
- JSON 备份与恢复机制可用;
- 浏览器本地存储读写正常。

演示数据 id 格式为 `选修一班_A01`—`选修二班_B30`,与真实名单编号一致,但 source 字段标 `demo`,不是真实测评结果。**这 60 条数据不是真实学生测评结果**,不反映任何真实学生的前后测成绩或能力维度,不能作为本课题的正式研究结论。

### 2. 演示数据的识别方式

为避免演示数据被误用为真实数据,平台与配套材料在以下位置做了明确标识:

| 位置 | 标识内容 |
|---|---|
| 平台首页顶部 | "当前数据为系统测试用演示数据,非正式测评结果" |
| 数据导出文件名 | 含 `demo_` 前缀,如 `demo_60人_20260725.csv` |
| CSV 文件 source 列 | 所有记录 source=demo |
| 截图标注 | 图5 说明文字明确"演示数据" |
| 本说明文件 | 本文件第三节 |

送审前再次核对上述四处标识完整、清晰、一致。

### 3. 演示数据不进入以下位置

- 中期研究报告的研究结论部分;
- 课题论文的数据分析部分;
- 任何对外汇报材料中涉及"学生能力提升""前后测对比"的表述;
- 课题特色材料中除"平台功能演示"以外的任何章节。

## 五、与校本课程总体测评的关系

归档中《2025 级高一校本课程测评情况分析报告(第一次)》共收集有效样本 787 份,反映的是**学校校本课程总体测评情况**,不是 FreeCAD 课程专项测评。两者关系如下:

| 维度 | 校本课程总体测评 | FreeCAD 课程专项测评 |
|---|---|---|
| 范围 | 全校高一所有校本课程 | 仅 FreeCAD 三维设计与 3D 打印课程 |
| 样本量 | 787 份 | 待真实测评形成 |
| 测评内容 | 学生对课程的满意度(满意/一般/不满意) | 六维度能力前后测+作品评分 |
| 用途 | 学校课程管理与课程实施环境佐证 | 本课题学生能力变化研究结论 |
| 当前状态 | 已完成第一次测评 | 待开展 |

校本课程总体测评可作为**课程实施环境**的佐证,但不能据此直接判断本课题对学生计算思维、建模能力或工程实践能力的提升。FreeCAD 专项研究结论须以专项前后测数据为准。

## 六、使用与核验建议

### 1. 中期检查时

- 平台首页与截图保留"演示数据"标识,不回避;
- 现场可演示平台功能(录入、查询、导出、导入、备份),证明工具可用;
- 不演示"数据分析结论",因为尚无真实数据;
- 本说明文件作为口径佐证,与平台一并提交。

### 2. 真实测评完成后

- 删除演示数据,导入真实数据;
- 将导出文件名 `demo_` 前缀改为 `real_`;
- 平台首页标识改为"真实测评数据,批次:[班级/日期]";
- 形成研究报告,经课题组核对后写入课题报告。
