## 打印机监控 MCP Server 实现方案

### 目标
为奔图 Pantum M6500NW 打印机创建一个 MCP server，让 Zcode 能直接查询打印机状态、管理打印队列，无需手动跑脚本。

### 实现内容

#### 1. 创建 MCP server 脚本
**文件**: `/Users/wangzirui/打印机监控/mcp/pantum_mcp_server.py`

基于现有 `check_pantum.sh` 的检测逻辑，用 Python 实现一个 stdio MCP server，提供以下工具：

| 工具 | 功能 |
|---|---|
| `printer_status` | 查询打印机当前状态：CUPS 状态、网络连通性（IPv4/IPv6/主机名）、队列任务数、URI、综合可用性 |
| `printer_queue` | 查看当前打印队列中的任务列表 |
| `printer_enable` | 启用打印机队列（cupsenable + cupsaccept） |
| `printer_cancel_all` | 取消队列中所有任务（cancel -a） |
| `printer_repair_uri` | 重新探测打印机 IPv6 地址并更新 CUPS 队列 URI（解决 IPv6 地址漂移问题） |

实现要点：
- 使用 Python 标准库 + MCP stdio 协议（JSON-RPC over stdin/stdout），不依赖第三方包
- 复用 `check_pantum.sh` 的检测逻辑：`lpstat` 采集 CUPS 状态、`curl` 探测网络、`ndp` 找 IPv6 地址
- 补全 GUI 环境 PATH（`/opt/homebrew/bin` 等），避免 Obsidian 同类问题

#### 2. 创建启动脚本
**文件**: `/Users/wangzirui/打印机监控/mcp/run_server.sh`

沿用 Zcode 现有的 shell 封装模式（参照 `run_server.sh`）：
- 补全 PATH
- 选择可用的 Python 3
- `exec python3 pantum_mcp_server.py`

#### 3. 注册到 Zcode MCP 配置
**文件**: `/Users/wangzirui/.zcode/cli/config.json`

在 `mcp.servers` 中新增条目：
```json
"pantum-printer": {
  "type": "stdio",
  "command": "/Users/wangzirui/打印机监控/mcp/run_server.sh",
  "args": [],
  "cwd": "/Users/wangzirui/打印机监控",
  "enabled": true,
  "timeoutMs": 600000
}
```

### 不做的事
- 不安装第三方 Python 包（纯标准库实现）
- 不重新启用定时监控（launchd），保持手动/按需调用
- 不修改 `check_pantum.sh`（保留原有手动检测脚本）

### 验证方式
注册后重启 Zcode 会话，调用 `printer_status` 工具确认能返回打印机状态。
