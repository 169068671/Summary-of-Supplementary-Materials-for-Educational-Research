## 研究课证据链

| 同一字段 | 必须保持一致的材料 |
|---|---|
| 日期 | 教学设计、课堂实施、听评课、照片文件名、作品生成时间 |
| 人员 | 执教人、听课人、活动参加人、本人签名 |
| 班级 | 教学设计、课堂实施、听评课、学生作品与测评批次（选修一班/选修二班） |
| 课题 | 教学设计、PPT、代码、作品任务、评价记录 |
| 学生编号 | FCStd、STL、实物照片、评价表、访谈和测评数据（A01–A30 / B01–B30） |

## 数据证据链

`测评工具 → 原始答卷 → 双人录入 → 差异核对 → 平台导入 → 抽样复核 → 统计分析 → 研究结论`

## 成果证明链

`成果正文 → 作者与题名 → 发表/获奖时间 → 刊物或主办单位 → 目录/证书/检索页 → 与课题的关联说明`

## 归档规则

- 公开材料不得出现不必要的学生姓名和身份信息。
- 匿名编号体系：选修一班 A01–A30，选修二班 B01–B30（2026-07-25 起，原 S01–S60 废止）。
- 行政班代码 G101–G118 仅在内部对应表保留，不写入公开送审材料。
- 匿名编号与姓名对应表由学校单独保管。
- 演示数据始终保留"演示数据"标识，不进入研究结论。
- 教学样件必须标为"课题组制作"，不得标为学生作品。
