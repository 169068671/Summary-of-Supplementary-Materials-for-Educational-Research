# 送审核验清单

## 真实性

- [ ] 所有日期、人员、班级、结论均来自真实记录
- [ ] 所有应签名处由本人签名
- [ ] 所有应盖章处已按要求盖章
- [ ] 无 `[待填]`、示例姓名、示例日期残留
- [ ] 教学样件与学生作品已明确区分
- [ ] 演示数据未写入研究结论

## 一致性

- [ ] 同一研究课的日期、班级、人员在全部材料中一致
- [ ] 学生匿名编号与源文件、STL、照片、评价表一致
- [ ] 校本课程总体测评与FreeCAD专项测评分开表述
- [ ] 论文成果的作者、题名、刊物、时间与证明一致

## 隐私与安全

- [ ] 公开材料不含学生姓名、联系方式等不必要信息
- [ ] 匿名编号对应表单独保管
- [ ] 原始问卷和成绩材料设置适当访问范围

## 装订与电子归档

- [ ] 纸质材料按通知第1至第5类设置隔页
- [ ] 第3项按3-1至3-5排列
- [ ] 第5项按5-1至5-6排列
- [ ] 大型PPT、网站、代码、平台已打印目录或代表页
- [ ] 完整电子附件随材料提交
- [ ] 签章文件单独核验，不与非正式模板混淆
