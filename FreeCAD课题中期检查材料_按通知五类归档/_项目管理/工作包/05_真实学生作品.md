# 工作包05：真实学生作品

> [!warning]
> 补充目录中的5组FCStd/STL是课题组制作的教学样件，只能作为教学资源，不能作为真实学生作品。

## 每件学生作品证据

- [ ] 学生匿名编号
- [ ] FreeCAD源文件
- [ ] STL文件
- [ ] 切片截图
- [ ] 打印实物照片
- [ ] 作品说明
- [ ] 作品评价表真实评分
- [ ] 必要的修改前后版本

## 建议命名

`班级_匿名编号_作品名.扩展名`

## 对应核验

- [ ] 编号与评价表一致
- [ ] 源文件可打开
- [ ] STL可切片
- [ ] 照片确为对应作品
- [ ] 作品形成时间与课程实施时间一致
