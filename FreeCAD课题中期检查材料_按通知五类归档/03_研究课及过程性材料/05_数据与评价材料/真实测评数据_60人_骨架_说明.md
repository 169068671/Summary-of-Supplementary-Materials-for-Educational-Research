# 真实测评数据 60 人骨架 CSV 说明

**编制日期**：2026-07-25
**文件**：`真实测评数据_60人_骨架.csv`

## 字段定义（与数据平台一致）

| 字段 | 含义 | 取值范围 | 填写时点 |
|---|---|---|---|
| id | 匿名编号 | 选修一班_A01 — 选修一班_A30 / 选修二班_B01 — 选修二班_B30 | 已填 |
| pre | 前测总分 | 0—100 | 前测实施后填 |
| post | 后测总分 | 0—100 | 后测实施后填 |
| space | 空间想象维度 | 0—100 | 评分后填 |
| decompose | 问题分解维度 | 0—100 | 评分后填 |
| parametric | 参数化思维维度 | 0—100 | 评分后填 |
| debug | 调试与迭代维度 | 0—100 | 评分后填 |
| engineering | 工程实践维度 | 0—100 | 评分后填 |
| interest | 学习兴趣维度 | 0—100 | 评分后填 |
| project | 作品评分 | 0—100 | 作品评价后填 |
| source | 数据来源标识 | real_待测 → real_已核验 | 已填 `real_待测` |

## 与演示数据的区别

| 维度 | 演示数据（`演示测评数据_30人.csv`） | 真实数据（本文件） |
|---|---|---|
| id 格式 | `学员A01` — `学员A30` | `选修一班_A01` — `选修二班_B30` |
| 样本量 | 30 | 60 |
| source 值 | `demo` | `real_待测` → `real_已核验` |
| 数据性质 | 系统测试用演示数据 | 真实前后测结果 |
| 用途 | 平台功能验证 | 研究结论依据 |
| 当前状态 | 已生成（无真实含义） | 骨架已建，待真实测评填充 |

## 填充流程（依据《数据平台演示数据与真实测评数据区分说明》）

1. 设计前测卷、后测卷、作品评价量表、课堂观察量表
2. 实施前测（FreeCAD 课程第一课时）
3. 过程性数据采集（课堂观察、作品评价、学生访谈）
4. 实施后测（课程结束时）
5. 原始问卷保管
6. 两人独立录入
7. 差异核对与修正
8. 填入本 CSV 对应字段
9. source 字段改为 `real_已核验`
10. 导入数据平台
11. 随机抽样核对至少 3 条记录
12. 形成分析报告

## 使用规则

- 本文件在真实测评完成前，所有分值字段保持空值
- 真实测评完成后，将本文件另存为 `真实测评数据_60人_已核验_[日期].csv`
- 平台首页标识同步改为"真实测评数据，批次：选修一班/二班 [日期]"
- 真实数据形成后，演示数据文件保留作历史记录，不删除
