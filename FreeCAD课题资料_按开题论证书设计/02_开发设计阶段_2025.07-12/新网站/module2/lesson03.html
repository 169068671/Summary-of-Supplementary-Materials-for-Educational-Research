上课前请完成以下预习任务

  • 复习模块一第2课的界面认识内容（菜单栏、树视图、3D视图、Python控制台）

🎯 本课教学目标

  • 熟练掌握FreeCAD视图操作与文件管理（新建、保存、另存为）
  • 切换到Sketcher工作台，了解草图工具栏
  • 能在XY平面上创建草图
  • 能用线段工具绘制基本图形（矩形、三角形）

📁 文件管理

新建文档：菜单 → 文件 → 新建（或Ctrl+N）

保存文件：菜单 → 文件 → 保存（或Ctrl+S），保存为 .FCStd 格式

命名规范：学号-姓名-项目名.FCStd（如 01-张三-钥匙扣.FCStd）

# 用Python控制台新建文档
import FreeCAD
doc = FreeCAD.newDocument("MySketch")
print("文档已创建：", doc.Name)

✏️ Sketcher草图工作台

切换到Sketcher工作台：顶部工作台选择器 → Sketcher

常用草图工具：

📏 线段：画直线，点击起点和终点

⭕ 圆：画圆，点击圆心和半径

🌙 圆弧：画弧线，点击起点、终点、半径

📐 矩形：画矩形，点击对角两点

🔹 多边形：画正多边形

📋 创建草图步骤

1. 切换到Sketcher工作台

2. 点击"创建草图"按钮

3. 选择草图平面（XY平面 / XZ平面 / YZ平面）

4. 在平面上用工具绘制图形

5. 添加约束（第4课详细学习）

# 用Python创建草图（预览，第4课详细学）
import Sketcher
doc = FreeCAD.newDocument("SketchDemo")
sketch = doc.addObject("Sketcher::SketchObject", "Sketch")
sketch.AttachmentSupport = doc.getObject("XY_Plane")
# 画一条线段：从(0,0)到(60,0)
sketch.addGeometry(Part.LineSegment(
    FreeCAD.Vector(0, 0, 0),
    FreeCAD.Vector(60, 0, 0)
), False)
doc.recompute()
print("草图已创建，含1条线段")
