# 网站与教学PPT重新制作方案

## 一、总体说明

- **依据**：开题论证书六模块，18课时（45分钟/课时）
- **不按旧版20课时**：旧版不符合开题论证书
- **技术**：网站用现代HTML+CSS+JS（离线可用），PPT用HTML网页版（浏览器全屏播放）
- **风格**：精美、内容丰富、高中生喜欢（渐变配色、卡片布局、动画效果、代码高亮）

## 二、18课时清单

| 模块 | 课时 | 课程 |
|---|---|---|
| 模块一：3D打印新视界与STEAM启蒙 | 2 | 第1课：3D打印与STEAM启蒙 / 第2课：FreeCAD初体验与安全规范 |
| 模块二：手动建模基础（FreeCAD） | 3 | 第3课：界面操作与草图 / 第4课：几何约束与尺寸约束 / 第5课：拉伸与实践项目1 |
| 模块三：编程建模入门 | 3 | 第6课：Python基础 / 第7课：代码控制几何体 / 第8课：循环与函数 |
| 模块四：编程建模进阶 | 3 | 第9课：参数化与布尔 / 第10课：数学函数建模 / 第11课：实践项目2/3 |
| 模块五：3D打印准备与切片 | 3 | 第12课：STL导出 / 第13课：Cura切片参数 / 第14课：打印实操 |
| 模块六：综合STEAM项目 | 4 | 第15课：选题与方案 / 第16课：建模与迭代 / 第17课：切片打印与文档 / 第18课：答辩 |
| **合计** | **18** | |

## 三、网站设计

### 目录结构
```
新网站/
├── index.html              ← 首页（课程介绍、六模块导航、动态效果）
├── css/style.css           ← 全站样式（渐变、卡片、动画、响应式）
├── js/main.js              ← 交互（滚动动画、代码高亮、导航）
├── module1/                ← 模块一（2课时）
│   ├── index.html
│   ├── lesson01.html
│   └── lesson02.html
├── module2/                ← 模块二（3课时）
├── module3/                ← 模块三（3课时）
├── module4/                ← 模块四（3课时）
├── module5/                ← 模块五（3课时）
├── module6/                ← 模块六（4课时）
└── assets/images/          ← 样件轴测图
```

### 设计风格
- 主色调：科技蓝→紫渐变（#667eea→#764ba2）
- 卡片式布局：圆角、阴影、hover动画
- 代码高亮：暗色主题代码块（VSCode风格）
- 响应式：手机/平板/电脑自适应
- 动画：滚动淡入、进度条

### 每课时页面内容
1. 课时标题与教学目标
2. 知识点讲解（图文并茂）
3. 课堂代码（高亮显示）
4. 作品展示（轴测图）
5. 课后任务/挑战
6. 进度导航

## 四、PPT设计

### 技术方案
HTML网页版PPT（reveal.js风格），浏览器全屏播放，每模块独立文件。

### 目录结构
```
新PPT/
├── index.html              ← PPT总目录
├── css/ppt.css            ← PPT样式
├── module1.ppt.html       ← 模块一PPT（2课时，8-12页）
├── module2.ppt.html       ← 模块二PPT（3课时，12-15页）
├── module3.ppt.html       ← 模块三PPT（3课时，12-15页）
├── module4.ppt.html       ← 模块四PPT（3课时，12-15页）
├── module5.ppt.html       ← 模块五PPT（3课时，12-15页）
└── module6.ppt.html       ← 模块六PPT（4课时，15-20页）
```

### PPT风格
- 全屏幻灯片，键盘左右切换
- 每页一个知识点，大字体、少文字
- 渐变背景、图标、动画转场
- 代码块高亮
- 作品轴测图嵌入

## 五、执行顺序

1. 先做网站首页+模块一（确认风格）
2. 确认后批量做模块二至六
3. 再做PPT（模块一先做，确认后批量做）
4. 最后验证完整性

## 六、注意
- 旧版网站和PPT保留不动，新版独立存放
- 新版按开题论证书六模块/18课时设计
- 样件轴测图嵌入网站和PPT
