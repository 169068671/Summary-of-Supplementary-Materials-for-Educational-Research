# 三阶六模块课程结构

> 依据：开题论证书"三、研究目标与内容" + "五、研究成果"
> "三阶六模块"课程结构：基础启蒙20学时、技术实践30学时、综合创新16学时

## 三阶六模块总览

| 阶段 | 能力目标 | 模块 | 学时 |
|---|---|---|---|
| 基础启蒙（L1-L2） | 基础操作 + 简单逻辑 | 模块一：3D打印新视界与STEAM启蒙 | 20学时 |
| 技术实践（L3-L4） | 算法思维 + 跨学科应用 | 模块二：手动建模基础（FreeCAD） | 30学时 |
| | | 模块三：编程建模入门 | |
| | | 模块四：编程建模进阶 | |
| | | 模块五：3D打印准备与切片 | |

| **合计** | | | **66学时** |

## 各模块详细内容（依据论证书原文）

### 模块一：3D打印新视界与STEAM启蒙
课程介绍，STEAM理念，3D打印技术原理、类型、应用场景，编程思维启蒙，安全教育等。

### 模块二：手动建模基础与实践（以FreeCAD为例）
FreeCAD软件界面、基本操作、视图控制、文件管理、基础几何体建模、简单组合建模练习等。

### 模块三：编程建模入门与逻辑构建
编程建模平台介绍（如集成于FreeCAD的编程模块或专门的编程建模软件）、编程基础（变量、循环、条件、函数等）、用编程控制几何体生成与变换等。

### 模块四：编程建模进阶与项目挑战
复杂参数化设计、算法应用（如分形、阵列）、结合数学函数建模、小型编程建模项目实践。

### 模块五：3D打印准备、切片操作与实践
模型修复与优化（STL检查）、切片软件（如Cura）操作、打印参数设置、支撑结构、3D打印机操作与维护、打印实践。

### 模块六：综合STEAM项目设计与成果展示
选题（结合生活、科技、艺术等）、项目规划、团队协作、融合手动、编程建模与3D打印技术完成综合项目、成果展示与答辩、项目反思。

## 能力进阶路径

```
L1-L2 基础启蒙          L3-L4 技术实践          L5-L6 综合创新
图形化编程界面          Python控制FreeCAD       基于仿真的工程优化
快速生成几何体          建模声波可视化装置      桥梁承重优化项目
```

## 创新特性

每层级配备"微认证"达标机制与"弹性挑战"扩展包，实现"保底不封顶"的分层教学。
